Вопросы

Чем это лучше overlay-виджетов (UserWay, accessiBe)?

Оверлеи не чинят разметку, ломают скринридеры и создают ложную уверенность — против accessiBe идёт класс-иск. A11yFix ремонтирует сам DOM и показывает каждую правку.

Мой сайт станет «compliant»?

Автоматика закрывает механические 20–40% проблем. Контраст, фокус-порядок и ARIA-паттерны — за живым специалистом. Мы честно пишем это в отчёте.

Замедлит ли сайт?

Скан — на кроне. DOM-правки — через output buffer ≤ 15 мс; страницы без нужных правок отдаются байт-в-байт.

Как установить?

Скачайте zip → Плагины → Добавить новый → Загрузить → Активировать. Меню A11yFix → «Run scan now».

FAQ

How is this better than overlay widgets (UserWay, accessiBe)?

Overlays don't fix markup, break screen readers and create false confidence — accessiBe faces a class action. A11yFix repairs the DOM itself and shows its work.

Will my site be "compliant"?

Automation covers the mechanical 20–40%. Contrast, focus order and ARIA patterns need a human expert — and we say so honestly in the report.

Will it slow my site down?

Scans run on cron. DOM repairs go through an output buffer (≤ 15 ms); pages needing no changes are served byte-for-byte.

How do I install it?

Download the zip → Plugins → Add New → Upload → Activate. A11yFix menu → "Run scan now".
