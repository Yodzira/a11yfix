## Why not an overlay / Почему не overlay

Overlay-виджеты (те, что накидывают тулбар поверх сайта) не чинят разметку, иногда ломают ассистивные технологии и создают ложную уверенность. A11yFix — противоположный подход:

- 🔍 **Аудит**: 9 правил — alt, иерархия заголовков, несколько h1, пустые ссылки и кнопки, поля без label, `lang` у `<html>`, `<title>`, «читать далее»-ссылки. Каждая находка — с серьёзностью и фразой «как чинить».
- 🛠 **Ремонт DOM**: безопасные правки (alt из медиабиблиотеки, `lang` на `<html>`, `scope` у заголовков таблиц) и рискованные — выключены по умолчанию.
- 👀 **Предпросмотр изменений**: правка показывает список «элемент → атрибут → новое значение» на захваченной странице до включения. Ничего не удаляется — правки только добавляют атрибуты.
- ⚡️ **Не тормозит**: скан — на кроне, не на посетителе; страница без нужных правок отдаётся байт-в-байт; 500 картинок при всех правках — +157 мс на полный рендер (замер стенда).
- 🧹 **Чистый uninstall**: таблица, опции и крон стираются полностью.
- 🤥 **Честная рамка**: автоматика закрывает механические 20–40% проблем. Контраст, фокус-порядок и ARIA-паттерны — за живым специалистом. Никаких «compliance в один клик».

## Установка / Install

1. Скачайте [`a11yfix.zip`](https://github.com/Yodzira/a11yfix/releases/latest/download/a11yfix.zip) (всегда последняя версия)
2. WP-админка → **Плагины → Добавить новый → Загрузить плагин** → zip → Активировать
3. Меню **A11yFix → Audit → Run scan now** — отчёт готов
4. Вкладка **Repairs**: включайте правки по одной, сначала глядя Preview
